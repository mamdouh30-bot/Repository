
🚀 Super Employee OS - الكود النهائي الجاهز للبيع باشتراك شهري
================================================================

📦 ما داخل الملف؟
- app/ : الكود الأساسي (FastAPI + Worker 24/7 + Billing)
- templates/ : صفحات البيع والداشبورد والأدمن
- static/robot.webp : صورة الموظف الخليجي البريميوم
- docker-compose.yml : تشغيل بضغطة واحدة

💰 كيف تبيع؟ المسار:
1. العميل يدخل موقعك / -> يختار باقة 99/199/299 AED -> يدفع عبر PayTabs
2. النظام يفعل اشتراكه تلقائيا -> ينقله ل /onboarding
3. يدخل توكنات واتساب وتيليجرام -> يبدأ الموظف يعمل فورا
4. انت ترى أرباحك في /admin

🌐 كيف ترفع على سيرفر مجاني 100%؟

الطريقة الأسهل (Railway.app - مجاني):
1. ادخل railway.app وسجل دخول ب GitHub
2. New Project -> Deploy from GitHub repo (ارفع هذا المجلد ل GitHub أولا)
3. في Variables ضع محتويات .env
4. سيعطيك دومين https://...up.railway.app
5. هذا الدومين ضعه في DOMAIN في .env

أو Render.com:
1. render.com -> New Web Service -> ارفع المجلد
2. Build Command: pip install -r requirements.txt
3. Start Command: uvicorn app.main:app --host 0.0.0.0 --port 10000
4. ضع متغيرات البيئة

لضمان 24/7 بدون توقف:
- ادخل UptimeRobot.com -> Add Monitor -> HTTP -> ضع https://yourdomain.com/health
- سيفحصه كل دقيقة ويعيد تشغيله لو سقط

🔑 كيف تحصل على مفاتيح واتساب وتيليجرام لعملاءك؟
- واتساب: developers.facebook.com -> أنشئ App -> WhatsApp -> انسخ Token و Phone ID
- تيليجرام: كلم @BotFather -> /newbot -> انسخ Token
